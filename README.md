# Flask + MySQL: авторизация

1. Создать БД и таблицу: выполнить `schema.sql` в MySQL
2. Установить библиотеки:

       pip install -r requirements.txt

3. В `database.py` указать свои user и password от MySQL
4. Запустить:

       python app.py

Открыть http://127.0.0.1:5000
